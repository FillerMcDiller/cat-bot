Items / Shop

The items system is split between inventory use and the shop. Items are defined in the bot code with descriptions, tiers, and effect text.

Shop

  • Kibble is the main shop currency.
  • Players can buy items, cosmetics, and utility resources.
  • Some shop offerings rotate or depend on state stored in JSON/database fields.

Item use

Items are consumed from inventory through the item manager flow, which handles selection, target checks, and confirmation prompts when needed.
