Inventory / Cats

The inventory page is the hub for your owned cats and items. It is backed by the web inventory flow in main.py and uses the user's stored session/profile data.

Cat browser

  • Shows all owned cats with filters for type, favorite state, and adventure state.
  • Supports sorting, paging, and quick actions on a selected cat.
  • Protects active/adventuring cats from accidental deletion or transfer.

Item browser

The same inventory interface also lists items, Kibble, rain minutes, and other stored resources.

Commands

/inventory /cats /items
