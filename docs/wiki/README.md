# Cat Wiki — Preview

This folder contains a lightweight static wiki for the Cat Bot. The `preview.html` file in this directory inlines the wiki CSS and Overview content so the repository viewer shows a styled page without requiring the JavaScript loader.

How to get the full interactive experience:

- Option A — GitHub Pages: enable GitHub Pages for this repository and serve the `docs/wiki` folder (or point Pages to the `docs` folder and move the wiki) — the interactive JS (`app.js`) and styles will run and the editor flow will work.
- Option B — Open locally: open `docs/wiki/index.html` in your browser (file://) to use the full interactive wiki (JS required).

Quick links:

- `preview.html` — static preview suitable for the repo viewer
- `index.html` — interactive wiki shell (requires JS)
