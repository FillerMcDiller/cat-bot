Catnip

Catnip is the mafia/bounty system. It tracks a user's level, active timer, assigned bounties, and available perks using the configuration in config/catnip.json.

Bounties

  • Users can get up to three main bounties plus an optional bonus bounty.
  • Bounties can ask for any cats, a specific type, or a rarity threshold.
  • When the bounty set is complete, the bot tells you to go to /catnip to pay up and pick a perk.

Levels and perks

The config defines level difficulty, bounty counts, cost, rarity weights, and perk pools. Perks are generated from weighted rarity tables and can include catch boosts, pack chances, rain triggers, and timer effects.

Key fields

catnip_level / catnip_active / catnip_price / catnip_amount / bounty_progress_* / bounty_type_* / reroll
