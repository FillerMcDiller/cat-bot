Prisms

Prisms are tradeable power-ups that slightly improve cat upgrade chances. The prism list is server-scoped and each prism has a unique generated name.

Crafting recipe

The crafting recipe is one of every cat type. If you are missing any type, the command will show the missing cats before it allows crafting.

Boosts

Prism boost scales with both the server-wide prism count and the user's own prism count. The page and footer show both values.

Limits

The server has a prism limit based on the generated prism name list, so crafting stops once that pool is exhausted.
