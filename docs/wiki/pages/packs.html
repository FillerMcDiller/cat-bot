Packs

Packs upgrade through eight main tiers: Wooden, Stone, Bronze, Silver, Gold, Platinum, Diamond, and Celestial. Festive is a separate seasonal pack.

Upgrade flow

Each pack has a 30% upgrade chance per step, so a low-tier pack can climb to a higher tier before it resolves into rewards.

Rewards

  • Cat amounts scale from the final pack value and spawn weights.
  • Some packs can also award Kibble.
  • Luck buffs can increase better reward outcomes.

Commands

/packs /gift
