Features

Inventory Browser

Open your inventory from the bot and browse cats in a cleaner web view. You can search by name or type, inspect a cat, rename it, play with it, and use supported items on it. You cannot give yourself items, packs, or cats from the site.

Trading

Trading is built for moving cats and resources between players inside Discord. The web hub does not replace trades; it only documents the flow so you know when to use /trade instead of the browser.

Gifting

/gift is for handing cats or allowed resources to someone else. The web UI intentionally blocks self-grants, so any item or cat you use here still comes from your own inventory.

Cat Actions

From the inventory browser, the action panel lets you rename a cat, toggle favorite, play to increase bond, and use supported bond items such as balls, dog treats, pancakes, and seasonal toys.

Inventory Viewer

Open this page from the Use Web UI button in /inventory and it will auto-connect to your profile. You can search cats, rename them, play with them, and use supported items here. No self-gifting.
