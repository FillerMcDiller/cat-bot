Wiki Info

This wiki is a lightweight, code-backed reference for KITTAYYYYYYY. Pages are stored as static HTML fragments and loaded into the wiki shell from docs/wiki/pages.

Edits are gated by a signed edit token and the server re-checks the editor's Discord role before saving.

What the bot tracks

  • Cat collections, bond, favorites, and adventures.
  • Items, packs, Kibble, rain minutes, and battlepass progress.
  • Cosmetics, achievements, prisms, and catnip bounty progress.

Where the data comes from

Core game state lives in the bot code, JSON files under data/ and config/, and the database models used by the bot.
