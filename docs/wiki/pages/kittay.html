KITTAYYYYYYY

This is the main cat bot. It handles spawning, catching, inventory, items, packs, battles, cosmetics, battlepass quests, prisms, and the catnip mafia system.

Main loops

  • Spawn cats in configured channels and catch them with the normal channel flow.
  • Run rain events for rapid cat spawning.
  • Refresh battlepass quests and scheduled race/rain systems.

Useful commands

/setup /forcespawn /catch /inventory /cats /items /shop /packs /battlepass /profile /cosmetics /prism /catnip
