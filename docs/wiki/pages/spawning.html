Cat Spawning

When a cat is caught, the bot calculates the next spawn time for that channel and stores it. If the bot restarts, it checks for overdue spawns and catches up.

Default messages

Spawn message:

{emoji} {type} cat has appeared! Type "cat" to catch it!

Catch messages are type-specific when configured, otherwise the bot uses the default catch text from the wiki overview page.

Rains

Rains pause the normal timing flow and spawn cats rapidly for a limited duration. They also override the usual slow spawn cadence for that channel.

Commands

/setup /forcespawn /changemessage /changetimings /rain
